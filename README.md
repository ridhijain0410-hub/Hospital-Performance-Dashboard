# Hospital Performance Dashboard | Power BI

## Project Overview
An interactive Power BI dashboard designed to analyze hospital performance, patient demographics, and operational efficiency.

## Tools Used
- Microsoft Power BI Desktop
- Power Query
- DAX
- Data Visualization

## Key Performance Indicators
- Total Patients: 500
- ICU Patients: 149
- Total Deaths: 14
- Readmitted Patients: 113
- Average Length of Stay: 6.14 days
- Average Waiting Time: 63.57 minutes

## Dashboard Features
- Interactive slicers for hospital, division, physician, age group, patient name, and surgical specialty
- Patient distribution by gender, hospital, and age group
- Discharge outcome analysis
- Geographical patient distribution
- Division-wise waiting time analysis
